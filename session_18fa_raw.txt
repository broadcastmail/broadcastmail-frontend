## How it's wired

- **`instrumentation.ts`** starts the Node MSW server automatically when `NODE_ENV=development` (covers your server-component `fetch`/`axios` calls, e.g. `getOnboardingStatus`).
- **`MSWProvider`** (in `app/layout.tsx`) starts the browser Service Worker the same way (covers client-side calls like the Resend form submit).

Both only activate in dev — so:

```
npm run dev
```

then open `http://localhost:3000`.
